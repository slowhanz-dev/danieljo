Workflow Nodes 0개 흐름

노드 하나를 완료하면 다음 노드가 자연스럽게 “지금 가능” 상태로 올라옵니다.

Work Board 0개 카테고리

이제 항목을 드래그해서 카테고리 간 이동할 수 있습니다. 항목 이름은 더블클릭으로 수정합니다.

간략 사용 메뉴얼

1. 아침에 보는 순서

  1. 맨 위의 지금 가능한 다음 노드만 먼저 봅니다.
  2. 오늘 처리할 노드는 1~3개만 고릅니다.
  3. 진행할 수 없는 일은 상태를 대기 또는 막힘으로 바꿔 머릿속에서 지웁니다.

2. 노드 처리 방식

  • 완료: 해당 단계가 끝났을 때 누릅니다. 다음 단계가 활성화됩니다.
  • 대기: 고객 답변, 배송 도착, 기관 발표처럼 내가 당장 못 움직이는 일입니다.
  • 막힘: 정보·견적·파일·결정이 부족해서 멈춘 일입니다.
  • 연락 칸에는 연락할 사람, 메모 칸에는 다음 행동을 적습니다.

업무 현황판 사용

  1. 항목 왼쪽의 ⋮⋮ 부분을 잡고 다른 카테고리로 드래그합니다.
  2. 항목 이름은 더블클릭해서 빠르게 수정합니다.
  3. 상태 배지는 선택 상자로 바꿀 수 있습니다.
  4. 각 카테고리 아래 입력창에 새 항목을 적고 Enter를 누르면 추가됩니다.

노드 테스트 방법

  1. + B2B 흐름을 눌러 하나를 만듭니다.
  2. “문의 수신 → 요구사항 확인 → 견적서 작성 → 샘플 발송 → 송장 전달 → 도착 확인 → 팔로업” 순서가 맞는지 봅니다.
  3. 첫 노드를 완료 처리하고, 두 번째 노드가 위 집중 영역에 올라오는지 확인합니다.
  4. 연락이 필요한 단계에는 연락처나 고객명을 적어봅니다.
  5. 며칠 써본 뒤 “노드 이름 / 상태 / 메모 필드”가 실제 업무와 맞는지 조정합니다.
이 파일은 테스트용입니다. 다만 서버 연결은 기존과 동일한 Firebase / dashboards / bunnar-main 문서를 사용합니다. 노드 데이터는 기존 보드 데이터와 별도 필드로 저장되어 기존 화면을 크게 건드리지 않도록 구성했습니다.
